
# Energy Consumption and Sustainability Analytics

An interactive Streamlit dashboard for analysing household electricity consumption patterns.

## Features

- Dataset upload
- Electricity consumption summary
- Monthly energy consumption chart
- Hourly electricity usage chart
- Weekday consumption chart
- Sub-metering comparison
- Correlation heatmap
- Data quality information
- CSV download options
- Energy-saving recommendations

## Dataset

Individual Household Electric Power Consumption Dataset.

Source: UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Google Colab
